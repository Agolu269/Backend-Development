# Lab 01 – Backend Development Fundamentals

A beginner-friendly Node.js and Express project demonstrating how to create an HTTP server and build basic API routes.

## Overview

This lab introduces backend development using Node.js and Express.js. It includes a welcome route, an About route, a route that returns the current time, and a custom 404 handler.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- npm
- Visual Studio Code
